AMBESHWAR STEELS LEDGER — ANDROID PWA

FILES
- index.html: the app
- manifest.webmanifest: install metadata
- sw.js: offline cache
- icon.svg: app icon

IMPORTANT
A Progressive Web App must be served from HTTPS (or localhost) to install and use offline.
Opening index.html directly from the phone's file manager is not enough.

EASIEST DEPLOYMENT
1. Upload all four files (index.html, manifest.webmanifest, sw.js, icon.svg) to the same folder on an HTTPS static hosting service.
2. Open the HTTPS website in Chrome on your Android phone.
3. In Chrome, tap the three-dot menu and choose "Install app" or "Add to Home screen".
4. Open the installed Ambeshwar Steels Ledger icon.

DATA & PRIVACY
- Ledger records are stored locally in the browser on that device.
- There is no account login, cloud sync, or automatic online backup.
- Use Reports & Backup > Download full backup regularly.
- Restore a JSON backup from Reports & Backup.
- Clearing browser/app storage can erase records. Keep backups in a safe place.

BALANCE RULE
Positive balance = you owe the distributor.
Negative balance = distributor owes you.
Purchase increases payable; payment made reduces payable.
Sales/claim increases receivable; amount received reduces receivable.

This is a basic ledger, not GST/accounting or tax software.
